METHODOLOGY USED
1. Advanced Log Analysis Methodology
The methodology for advanced log analysis focuses on identifying security incidents by correlating logs from multiple sources and detecting anomalies.

Steps Followed:
1.Collected logs from endpoints, network traffic, and authentication systems.
2.Identified suspicious patterns such as repeated failed logins (Event ID 4625).
3.Correlated authentication logs with outbound network activity.
4.Applied anomaly detection rules (e.g., high data transfer).
5.Enriched logs using contextual data such as IP geolocation.

Outcome:
This methodology helps in detecting brute-force attacks, lateral movement, and abnormal behavior while reducing false positives.
